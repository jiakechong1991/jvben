
# 说书人agent
【产品目标】:
1. 了解故事梗概，可以自由跟他问答，表现出说书人的性格和人设
2. 可以 对“整篇小说” 完成分析：
  a. 角色，地点，法宝， 大致经历
3. 可以根据用户的query，较好的解释相关的故事。

【技术实现】：
1. 本质上是文档(跳跃式)问答，所以要对文档进行加工理解
  a. 构建知识图谱
2. 对用的query进行qp
3. 记忆区 划分后，只要能及时的完美的调整记忆区，应该就可以
4. 总的说：保持LLM不变时，只要能根据query，及时的组织好prompt，就行
5. 还有一个种路线： 把小说文本 微调到 LLM中

1. memgpt --- 上下文 记忆组织能力 【记忆如何存储】
2. lightrag ---- 文档搜索能力 【记忆如何唤醒】
