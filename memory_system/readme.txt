###记忆检索系统
目标：找到跟“当前思维链”相关的所有记忆，组织这些记忆是后续模块的事情
特性：
1. 具备 大跨越 长度的 检索能力 
  1. 必须 很长的对话历史，能找出其中的 相关对话
  2. 很长的文本，找出跟其有关的 参考点
2. 具备 多种记忆形态 的检索能力

实现：
1. 文本检索--关键词
2. 向量检索
3. 图谱检索
